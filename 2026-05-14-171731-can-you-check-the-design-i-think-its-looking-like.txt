⏺ Honest review — I read the code rather than just the screenshots.

  The good news: it's already pretty anti-AI

  What you have is the opposite of AI-slop. AI-slop = purple-blue gradients,
  glass cards, shadcn defaults, "Built for the future." You're running aged
  manila paper (#EFEAD8), red rubber-stamp ink, hand-drawn SVG marks with
  feTurbulence displacement, masking tape, receipts, marker highlights,
  ink-circle, scribble underlines, stroke-draw studio mark, ink-trail cursor,
  page-turn corner, editorial italic serif + JetBrains Mono. That's craft-tier —
   Pentagram/Wieden zine territory, not Cursor template.

  Why it can still read as AI-generated

  Five tells, in order of how cheaply you can fix them:

  1. Everything-at-once syndrome. Stamps + tape + receipts + ink circles +
  scribbles + marker + serial numbers + coordinates + grain + ink trail + page
  turn + drift animation, all on the hero. AI uses every pattern at once. A
  hand-designed studio commits to 2–3 motifs and uses the rest sparingly. Fix: 
  pick a primary motif per page. Hero leans paper-grid-and-stamp; Philosophy 
  leans pure typography. Demote the rest.
  2. Copy has GPT cadence. "Creative first · human second · AI for speed."
  "tokens burned so you don't have to." "Make it work / Make it true / Make it
  disappear." "the intelligent systems behind ~good~ great products*." Triplets,
   em-dashes-as-rhythm, that tidy clever-aphorism shape. Fix: rewrite in one 
  sitting, out loud, deliberately uneven. One short sentence next to one long 
  one. Use proper names. Reference a real client moment.
  3. Symmetric "asymmetry." tilt-l-2 = -3deg / tilt-r-2 = +3deg. corner-tl
  mirrored four ways. Hand-placed things are not mirrored. Fix: use odd, 
  non-mirrored values. -2.8deg, +4.1deg, -1.3deg. Different seed on each 
  feTurbulence.
  4. The aesthetic itself is a 2024–2026 trend. Paper + red stamp + serif italic
   + tape is now its own AI-reachable preset. Off-Brand, Locomotive, half of
  Awwwards. Fix: add one weird specific thing the trend doesn't have. A real 
  photographed scan of your notebook as a section break. A favicon that's a 
  smudge. A live-typed plaintext changelog. Footnotes that actually footnote.
  5. Grid-perfect underneath the doodles. The 1.7fr/1fr hero grid, the
  equal-spaced stat band, the perfectly-stacked receipt — the bones are AI-tidy.
   Fix: break one thing per section. Hero: let the receipt overlap the headline.
   Stats: kill one column so it's 3, not 4. Headline: indent one line 
  dramatically further than the others.

  What I would NOT change

  The palette, typography stack, studio mark, ink-trail cursor, and page-turn.
  Those are the real signature and they're working.

  Want me to do the surgical pass — break the symmetries, thin the motifs per
  section, and rewrite the copy?

  The pitch: the site is a control room

  Not "control room aesthetic" — actually a working SCADA-style live dashboard
  of the studio itself. You run industrial/IoT systems for a living. The brand
  promise is "things stay up under load." So the marketing site is a live ops
  dashboard for the studio. The design isn't decoration — it's telemetry.

  What this looks like concretely:

  - Hero is a live readout, not a headline. Real metrics from real systems:
  GitHub commit feed (you have 6 public repos), build status of your own infra,
  "minutes since last incident" counter, current Bangalore weather pulled live,
  current PR queue. Each tile is a real probe.
  - Work isn't a portfolio grid — it's a system map. Nodes are clients/projects;
   edges are disciplines that connected them; one project pulses when it's
  running. Pan and zoom around it like a real ops diagram.
  - About is a runtime log. 2026-05-14 09:12  mayur: pushed agrigrid v2.3 /
  2026-05-13 22:40  deploy: irctc-report ok / 2024-03-04 11:00  founded: 
  snxstudio.com. Ten years of real timestamped events, scrollable.
  - Contact isn't a form — it's subscribe to availability. You see Mayur's
  current capacity ("1 engagement / Q3 2026") as a real signal, not marketing
  copy. When you submit you get a queue position.
  - Typography is two faces only: a precise neo-grot like Söhne Mono / Berkeley
  Mono for readouts, and one heavy display for hero numerals. No serif italic.
  No paper. No tape. No stamps. No grain.
  - Color is functional: black + signal-green for "live," signal-amber for
  "watching," signal-red for "incident." Used only when something's actually in
  that state. Background is near-white. That's the whole palette.
  - No animations for vibes — only state changes animate (a metric ticks up, a
  node turns green). Everything else is dead still.

  Why this beats every preset:

  1. It can't be cloned by a prompt — it needs real data plumbed in.
  2. It demonstrates the product (you build live systems) instead of describing
  it.
  3. It ages backwards: most studio sites get stale; this one updates itself.
  4. Industrial-grade clients (Ministry of Power, energy, logistics) immediately
   read "these people ship live ops."
  5. No known studio is doing this. Closest reference is the internal Grafana 
  board of a serious infra company, productized as a brand surface. That's the
  gap.

  The cost: it's real engineering, not just CSS. You need a tiny backend feeding
   signals (most can be cron'd from GitHub API + Cloudflare Analytics + your own
   infra). Probably 3–5 days of work to wire up before any visual design begins.

  If you want to soften the bet, I can do a static-mock control room first —
  same aesthetic, no real backend, fake-but-believable numbers — and we plumb in
   real signals over time.

  Want me to start? I'll begin by gutting the current home, replacing it with a
  single live-dashboard hero (static-mock numbers for now), and we evaluate from
   there.
